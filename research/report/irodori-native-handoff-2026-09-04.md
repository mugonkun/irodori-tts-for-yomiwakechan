### 1-5 ⑤ CPU 合成は可（遅さはケアしない）（`36` §5・`29` §2-2）

- **事実**＝`resolve_runtime_dtype` は **CPU×bf16 を `ValueError: precision='bf16' currently requires CUDA or XPU device.` で弾く**（`inference_runtime.py:306-310`・実射）。fp32×auto は GPU が見えないと黙って CPU に落ちて 200（2 文字・10 steps で 267 s＝340 倍）。上流 UI の `list_available_runtime_precisions(device)` は cpu で `["fp32"]` しか返さない＝device↔precision を構造的に連動させている（写すべき挙動）。
- **本体への訂正**＝`IrodoriConstants.cs:181-186` の「CPU×bf16 は未測・動作見込み」は外れ。既定 bf16（`:224-232`）のままでは CPU 機で 1 発も通らない（`PRELOAD=true` なら起動失敗・`false` なら全合成 500）。
- **数値**＝CPU fp32 OMP=8＝短文 40 steps RTF 3.27・10 steps 1.79・参照 30 s ありで +36 %（`13`・`31`）。
- **未確認**＝CUDA wheel を入れた NVIDIA 無し機で CPU 合成が 200 で返るか（`21` §4 は `is_available()=False` まで）＝一般論では動く見込み・断定しない（`36` W-1）。
- **本体が決めること**＝CPU の露出（UI だけか本体からも選べるか）・精度を device と自動連動させる主体（本体定数の改訂か配布版のランチャか）。

### 1-6 ⑥ UI で GPU／CUDA 版／パラメータ／参照を試す・本体司令は UI の GPU を暗黙に使う（`36` §6・§7・報告 §10-2）

- **「暗黙」は原文上そうならざるを得ない**＝要求 JSON にも CLI にも device 欄は無く、device は Server プロセスの env 2 本（`IRODORI_MODEL_DEVICE`／`IRODORI_CODEC_DEVICE`）だけで決まる（1 プロセス 1 デバイス）。→ 本体の要求 JSON に GPU 欄を足す提案は不要。

### 1-7 ⑦ 参照ボイス檔＋名付け＝話者（`37` §3・`38` §1）

### 1-8 ⑧ 参照なし＝話者名「デフォルト」（`37` §4）

- **事実（実射）**＝`voice:"デフォルト"` は 404 でなく **400**（voices の絶対パスを漏らす）。`"default"` も不可。通る予約語は `none/no_ref/no-ref/null/text-only`。写像 3 本＝① `irodori.no_ref=true`（`allow_no_ref_voice=false` でも通る＝最も頑丈・ただし **voice を丸ごと無効化**＝`voice` と同時送信すると参照が黙って落ちる）／② `voice:"none"`（設定 1 つで全滅＝現行アダプタはこれ）／③ **`voices.json` に `{"デフォルト":{"no_ref":true}}`（一覧にも出る・`allow_no_ref_voice=false` でも生きる＝`38` 実射 13）**。
- **no_ref のときの声**＝Irodori 自身の声（caption のみ・`35` 追記）。caption は空文字・空白のみが 400＝「空」は欄ごと省略で表す。
- **帰結**＝③で「デフォルト」が一覧に出る（並びはコードポイント順＝`["none","zunda","デフォルト"]`・先頭に出すなら配布版が並べ替える）。`allow_no_ref_voice=false` で上流由来の `none` を消せる（推奨）。事実＝`voice` と `no_ref` を同時送信すると参照が黙って落ちる＝契約で同時送信を禁じる（推奨）。

## 7. 主席の追加実射＝日本語パスの参照 wav で実合成が通るか（`37` U-37-1）

**通る（soundfile 経路）**＝2 つの実射（lab の CPU 実ランタイム・torch 2.10・fp32・`torchaudio.load` を soundfile に差し替え）。

- (b) `_load_audio` の直呼び（主席の対話実行・出力は未保存）＝日本語ファイル名 `tmp/39/ずんだもん 10秒.wav`・その絶対パス・日本語ディレクトリ越しの 3 つがいずれも読めた（`(1, 250368) @ 24000`・`(1, 240000) @ 24000`）。
