# irodori-TTS for 読み分けちゃん 使い方

Windows のパソコンで、書いた文をその場でしゃべらせるアプリです。Python も、黒い画面も要りません。

## 1. 入れる

1. 公式ページから、お使いのパソコンに合う方を落とします。
   - **RTX（CUDA）**＝NVIDIA のグラフィックス（GeForce・RTX など）のパソコン
   - **Radeon（ROCm）**＝AMD の Radeon のパソコン
   - どちらか分からないときは、`Windows` キー ＋ `X` →「デバイス マネージャー」→
     「ディスプレイ アダプター」を開いて、NVIDIA と書いてあれば RTX（CUDA）です。
2. 落としたファイルをダブルクリックし、「次へ」「インストール」「完了」を押します。
   管理者のパスワードは要りません。
   ※「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」。

［**画像 1：インストーラの完了画面**］ — **撮影待ち**（v2.0 の画面で撮り直します）

**RTX（CUDA）と Radeon（ROCm）は別のアプリです。** 同じパソコンに両方入れられますが、
設定も、追加した声も、ダウンロードした物も、版ごとに別々です（RTX（CUDA）で追加した声は、Radeon（ROCm）には出ません）。
**同時に開くことはできません。** あとから開いた方は「ほかのソフトが、このアプリのつなぎ口を
使っています」と出ます。片方を閉じてから、もう片方を開いてください。

**Radeon（ROCm）で動くことを確かめたのは Ryzen AI MAX+ 395（Radeon 8060S）の 1 機種だけです。** ほかの Radeon で動くか・どのくらいの速さかは測っていません。

## 2. はじめの準備（1 回だけ・10 分ほど）

アプリが開くと、はじめの準備の画面が出ます。

1. お知らせを読み、チェックを入れて〔次へ〕。
2. 〔準備を始める〕を押し、ネットにつないだままお待ちください（約 5.3 GB・10 分ほど）。
3. 途中で 1 度、Microsoft の部品を入れるために Windows の許可の窓が出ます。「はい」を押してください
   （「いいえ」を押すと、しゃべらせられないことがあります）。
4. 「使えます。」と出たら終わりです。

［**画像 2：はじめの準備の進み具合**］ — **撮影待ち**（v2.0 の画面で撮り直します）

動かし方（CUDA 13.0 / CUDA 12.6 / ROCm / CPU）は**アプリが自動で選びます**。
自分で選び直したいときは、設定の「詳細（上級者向け）」で変えられます。
途中でやめても、次に開いたときは続きから始めます。最初からにはなりません。

## 3. しゃべらせる

声を選び、文を打って、〔しゃべらせる〕を押します。1〜2 秒で鳴ります。

［**画像 3：しゃべらせているところ**］ — **撮影待ち**（v2.0 の画面で撮り直します）

- **品質**＝「はやい」か「きれい」を選べます。
- **話し方の指示**＝「明るく」「落ち着いて」など、自由に書けます（空でもかまいません）。
- **速さ**＝1.0 がふつうです。
- 〔音声ファイルに保存…〕で wav として保存できます。

## 4. 読み分けちゃん2 から使う

このアプリを**開いたまま**にしておくと、読み分けちゃん2 の側でエンジンとして選べます。
こちら側で必要な操作はありません。読み分けちゃん2 が自動で見つけます。
声は、このアプリの「声」の画面の名前がそのまま出ます。

**アプリを閉じると読み上げも止まります。** 配信の間は開いたままにしてください。
配信中にこのアプリで〔しゃべらせる〕を押すと、「読み上げが終わるまでお待ちください」と出ます。
読み上げが終われば、そのまま使えます。

## 5. 声を増やす

「声」の画面 → 〔**声を追加する**〕を押し、元にする音声ファイル（wav）を選んで名前を付け、
〔**この声を追加する**〕を押します。
10〜30 秒くらいの、その人だけがしゃべっている録音がよく合います。
追加した声は、読み分けちゃん2 からも同じ名前で選べます。

選んだ音声ファイルは、アプリが**写しを取り込んで**使います。**あなたが選んだ元のファイルは動かしません。**

**実在する人の声を、本人の許しなくまねることは、この音声合成の利用条件で禁じられています。**
元にする音声は、使ってよいと許しを得た物だけにしてください。

## 6. 困ったときは（症状から引く）

### 準備の途中で止まった
窓を閉じて、もう一度開いてください。**続きから始めます。**
空きが足りないと出たときは、要らないファイルを消してから、もう一度お試しください
（準備には空き 12 GB ほどが要ります）。

### 「この GPU では、いまの動かし方が使えません」と出る
グラフィックスドライバが古いためです。画面に出ている釦を押すと、そのパソコンで動く方法に切り替えて
準備し直します。ドライバを新しくしてから開き直しても直ります
（NVIDIA は 580.00 以上で CUDA 13.0、528.33 以上で CUDA 12.6 が使えます）。

### 「対応するグラフィックスが見つかりませんでした」と出る
NVIDIA か AMD のページから、最新のグラフィックスドライバを入れて開き直してください。
グラフィックスが無いパソコンでも動きますが、とても遅いので配信には使えません。

### 「ほかのソフトが、このアプリのつなぎ口（18088）を使っています」と出る
まず、**もう一方の版（RTX（CUDA）／Radeon（ROCm））を同時に開いていないか**確かめてください。
2 つは別のアプリなので、同時には開けません。
それでも出るときは、どのソフトが使っているかを調べます。`Windows` キー ＋ `X` →「ターミナル」を開き、
`netstat -ano | findstr 18088` と打つと分かります。右端に出る番号を、タスク マネージャーの
「詳細」タブの「PID」の列で探すと、そのソフトの名前が出ます。
そのソフトを閉じてから、このアプリを開き直してください。
古い版のこのアプリが残って動いていることもあります。

### 読み分けちゃん2 が見つけてくれない
このアプリの窓が開いていて、上の帯が「**使えます**」になっているか確かめてください。
「準備しています…」の間はまだ使えません。
読み分けちゃん2 の側で、このエンジンを 1 度だけ選ぶ（有効にする）操作が要ります。
読み分けちゃん2 の設定で読み上げエンジンの一覧を開き、このアプリを選んでください。
※ このエンジンに対応した版の読み分けちゃん2 が要ります。

### 声が出ない・途中で切れる
品質を「はやい」にして、文を短くしてお試しください。
それでも直らないときは、いちど閉じてから開き直してください。

### 「アプリのファイルが壊れているようです」と出る
アプリを入れ直してください（上書きで入れ直せます）。**追加した声と設定は残ります。**
それでも直らないときは、いちど消してから入れ直してください。
※ 消すと、ダウンロードした物だけでなく、**追加した声と設定も一緒に消えます**（→ §9）。
入れ直したあとに、はじめの準備をもう一度やることになります（約 5.3 GB・10 分ほど）。

### それでも直らない
〔このアプリについて〕の〔**報告用のログを保存**〕を押すと、送るための記録が 1 つのファイルにまとまります。
そのファイルを添えて、X の **@yomiwakechan**（https://x.com/yomiwakechan ）までお知らせください。
（画面の〔ログを開く〕でも、記録のファイルの場所を開けます。）

## 7. 新しい版に上げる

上書きで入ります。設定と、自分で追加した声はそのまま残ります。
新しくなった分だけを、次に開いたときに取り直します。5.3 GB をもう一度落とし直すことはありません。

## 8. ファイルの場所

ふだんは開く必要はありません。設定の「詳細（上級者向け）」の「ファイルの場所」から
〔フォルダを開く〕で開けます。版ごとに別の場所です。

- RTX（CUDA）＝`%LOCALAPPDATA%\irodori-tts-ywk-cuda\`
- Radeon（ROCm）＝`%LOCALAPPDATA%\irodori-tts-ywk-radeon\`

ダウンロードした一式・取り込んだ声・設定・記録は、この中に入っています。
場所は変えられません。

## 9. 消す

Windows の「設定 → アプリ」から消せます。
消した方（RTX（CUDA）か Radeon（ROCm））が自分の場所に置いていた物（ダウンロードした一式・取り込んだ声・設定・記録）は
**すべて一緒に消えます**。**何も聞かれません。**
**声を追加するときに選んだ、あなたの音声ファイルには触れません。** そのまま残ります。
両方の版を入れている場合、消えるのは消した方だけです。もう片方はそのまま使えます。

## 10. このアプリについて

非公式のアプリです。もとになった音声合成 Irodori-TTS の作者（Aratako 氏）とは関係がありません。
うまく動かないときも、Aratako 氏へは問い合わせないでください。
出した音声には、AI が作った音であるという目印（人には聞こえません）が入ります。外す方法はありません。
うまく動かないときは、X の **@yomiwakechan**（https://x.com/yomiwakechan ）までお知らせください。
