**文字を打つと、しゃべります。** 読み分けちゃん2 の読み上げにも使えます。

**この版で直したこと**
- **はじめの準備の最後で「止まりました。」と出ることがあったのを直しました。** ダウンロードの直後の
  1 回目は声の読み込みに数分かかることがあり、そこで待つのをやめていました。いまは読み込みが
  終わるまで待ち、待っている間は「声を読み込んでいます。」と出します。
- **設定で選んだ動かし方が、次に開いたときに勝手に戻ることがあったのを直しました。**
  自分で CUDA 12.6 を選んだパソコンは、そのまま CUDA 12.6 で準備します。
- **設定の「詳細」の動かし方の一覧が、内部の名前のまま出ていたのを直しました**
  （「CUDA 13.0」「CUDA 12.6」「ROCm」「CPU」と出ます）。

**落とす物**
- **RTX（CUDA）** — NVIDIA の GeForce / RTX などのパソコンの方
  （`irodori-tts-ywk-setup-v2.0.1-cuda.exe`）
- **Radeon（ROCm）** — AMD の Radeon のパソコンの方（確かめられているのは Ryzen AI MAX+ 395 ／ Radeon 8060S）
  （`irodori-tts-ywk-setup-v2.0.1-radeon.exe`）

**はじめて開いたときに、動かすための一式（約 5.3 GB）をダウンロードします**（10 分ほど）。
必要なもの＝Windows 11 / 10（64 ビット）・空き 12 GB ほど・はじめの準備のときだけネット接続。
はじめての方は**公式ページの「使い方」**をご覧ください＝https://mugonkun.github.io/irodori-tts-for-yomiwakechan/
困ったときは X の **@yomiwakechan** までお知らせください。

**判っている制約**
- CUDA 13.0 にはグラフィックスドライバ 580.00 以上が要ります（528.33 以上なら CUDA 12.6 で動きます）。
- Radeon（ROCm）は Ryzen AI MAX+ 395 ／ Radeon 8060S でしか確かめていません。
- RTX（CUDA）と Radeon（ROCm）は別のアプリです。同じパソコンに両方入れられますが、設定も、追加した声も、
  ダウンロードした物も別で、同時には開けません。
- 読み分けちゃん2 で使う間は、このアプリを開いたままにしてください。
