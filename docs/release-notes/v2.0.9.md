**文字を打つと、読み上げます。** 読み分けちゃん2 の読み上げにも使えます。

**この版で直したこと**
- **〔このアプリについて〕からの更新が、押す所のない形になりました。** これまでは更新のインストーラーが
  〔インストール〕と〔完了〕を押すのを待って止まり、配信中は裏に隠れて「アプリが落ちたまま戻らない」ように
  見えることがありました。この版からは進み具合の小さな窓だけが出て、終わると自動でもう一度開きます。
- **注意＝この直しは、この版から次の版へ更新するときから効きます。** v2.0.8 以前からこの版へ更新するときは、
  まだ前の形なので、インストーラーの画面で〔インストール〕と〔完了〕を押してください。

**入れ方**
- RTX（CUDA）のパソコンは `irodori-tts-ywk-setup-v2.0.9-cuda.exe`、Radeon（ROCm）のパソコンは
  `irodori-tts-ywk-setup-v2.0.9-radeon.exe` を実行します。前の版の上から入れられます（声と設定はそのまま）。
- v2.0.7 以降をお使いの方は、〔このアプリについて〕の〔新しい版を確認〕からも入れられます（上の注意のとおり、
  今回だけは〔インストール〕と〔完了〕を押してください）。
- はじめて入れる方は、起動後の「はじめの準備」で必要な物（約 5.3 GB）をダウンロードします。

**知っておいてほしいこと**
- GPU メモリが 8 GB のパソコンで長時間の配信をする方は、設定 › 詳細（上級者向け）の「GPU メモリの上限」に **5** を
  入れてください（v2.0.8 で最小値を 5 GB にしました。8 時間の連続読み上げで、Radeon 5.1 GB・RTX 4.7 GB で頭打ちになり、
  失敗も遅くなることもないのを確かめています）。
- Windows の「スマート アプリ コントロール」が有効なパソコンでは、このアプリの読み上げの準備が
  動かないことがあります。**このアプリが使う部品（他の方が作ったプログラムの一部）を Windows が止めるためです。
  設定は Windows セキュリティ → アプリとブラウザー コントロール → スマート アプリ コントロール にあります。
- 8 GB の RTX そのものでの長時間の実測はまだです（測ったのは 24 GB の RTX と Radeon です）。上限 5 GB で
  なお苦しいときは、X の @yomiwakechan までお知らせください。
- CUDA 13.0 にはグラフィックスドライバ 580.00 以上が要ります（528.33 以上なら CUDA 12.6 で動きます）。
- Radeon（ROCm）は Ryzen AI MAX+ 395 ／ Radeon 8060S でしか確かめていません。
- Radeon（ROCm）では、初めての長さの音声を作るとき、透かしを入れる処理に 1〜2 秒かかることが残っています。
- RTX（CUDA）と Radeon（ROCm）は別のアプリです。同じパソコンに両方入れられますが、設定も、追加した声も、
  ダウンロードした物も別で、同時には開けません。
- 読み分けちゃん2 で使う間は、このアプリを開いたままにしてください。
