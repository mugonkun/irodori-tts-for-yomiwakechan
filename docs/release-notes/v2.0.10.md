**文字を打つと、読み上げます。** 読み分けちゃん2 の読み上げにも使えます。

**この版で直したこと**
- **読み上げに、意味の通らない言葉が混じることがあった問題を直しました。** 原因は、Irodori-TTS が対応していない
  絵文字です。対応していない絵文字が文に入ると、その絵文字のぶんだけ「読む中身の無い時間」が作られ、そこに
  予測できない音や言葉が入っていました。この版からは、**Irodori-TTS が対応している 45 種の絵文字**（😆 喜び・
  😭 泣き声・🤭 笑い・⏸️ 間・🐢 ゆっくり など）はそのまま効き、**それ以外の絵文字は読み上げる前に取り除きます**。
  取り除いた絵文字は〔ログ〕タブに 1 行で残ります（文の中身は残しません）。
- 絵文字を取り除いた結果、読む文字が残らないとき（絵文字だけのコメントなど）は、音を出さずに次へ進みます。
  これまで読み分けちゃん2 の側に「本体側の不具合」と出ていた形も、この版からは出ません。
- 読み分けちゃん2 の辞書で絵文字に読みを付けている場合は、これまでどおり辞書のほうが先に効きます。

**入れ方**
- RTX（CUDA）のパソコンは `irodori-tts-ywk-setup-v2.0.10-cuda.exe`、Radeon（ROCm）のパソコンは
  `irodori-tts-ywk-setup-v2.0.10-radeon.exe` を実行します。前の版の上から入れられます（声と設定はそのまま）。
- v2.0.9 をお使いの方は、〔このアプリについて〕の〔新しい版を確認〕から押す所なく入れ替わります。
  v2.0.8 以前からは、インストーラーの画面で〔インストール〕と〔完了〕を押してください。
- はじめて入れる方は、起動後の「はじめの準備」で必要な物（約 5.3 GB）をダウンロードします。

**知っておいてほしいこと**
- 対応している絵文字の一覧は、Irodori-TTS のモデルの配布ページにある `EMOJI_ANNOTATIONS.md` です。
  一覧の下の方の絵文字は、作者によると学習した例が少なく、効き目が弱いことがあります。
- 絵文字が入っていないのに言葉が混じる場合（文が 1〜3 文字と極端に短いときなど）は、絵文字とは別の性質で、
  この版では直っていません。X の @yomiwakechan までお知らせください。
- 読み分けちゃん2 で「名前をキャッシュする」を使っている方で、名前に絵文字が入っている人の古い読みが残るときは、
  その設定をいちど外してから戻すと、古い読みが消えます。
- GPU メモリが 8 GB のパソコンで長時間の配信をする方は、設定 › 詳細（上級者向け）の「GPU メモリの上限」に **5** を
  入れてください。
- Windows の「スマート アプリ コントロール」が有効なパソコンでは、このアプリの読み上げの準備が
  動かないことがあります。設定は Windows セキュリティ → アプリとブラウザー コントロール → スマート アプリ コントロール にあります。
- CUDA 13.0 にはグラフィックスドライバ 580.00 以上が要ります（528.33 以上なら CUDA 12.6 で動きます）。
- Radeon（ROCm）は Ryzen AI MAX+ 395 ／ Radeon 8060S でしか確かめていません。
- RTX（CUDA）と Radeon（ROCm）は別のアプリです。同じパソコンに両方入れられますが、設定も、追加した声も、
  ダウンロードした物も別で、同時には開けません。
- 読み分けちゃん2 で使う間は、このアプリを開いたままにしてください。
