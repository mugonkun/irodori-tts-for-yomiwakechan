## これは何か

- **Python を知らなくても導入できる、単体で使える日本語 TTS アプリ**です（Python も pip も uv も触りません）。
- **初めて起動したときに、動かすための一式（実行系とモデル・数 GB）をネットから取り寄せます**（10 分程度）。
  他の方が作ったプログラムやモデルは配布物に同梱しない方針なので、そのぶんをその場でお使いの機体へ入れます。
- **読み分けちゃん2 の 10 番目のエンジン**としても使えます＝アプリを開いている間 `http://127.0.0.1:18088` で
  待ち受け、本体が `/health` で見つけます。
- 既存の Irodori-TTS-Server（8088）とは別物で、**併用できます**。
- **プリセット話者 12 名**を同梱しています＝もち子さん（セクシー／あん子）・ちび式じい・つくよみちゃん・
  KANA（ないしょばなし）・MANA（いっしょうけんめい）・おふとんP（きざ）・おふとんP（のーまるv2）・
  琴葉茜（関西弁）・吉田くん・月読アイ・月読ショウタ・シャンパンコール（ホスクラ）。
  自分の参照 wav を足して話者を増やすこともできます（「話者」タブ）。

## この版で直したこと

- **窓の × で、アプリごと終わるようになりました。**前の版は × で窓が隠れるだけで、通知領域（タスクトレイ）に
  居座り、サーバも GPU のメモリ（VRAM）も抱えたままでした。いまは **× ＝終了**で、閉じるときにサーバの処理木を
  終わらせてから落ちます＝**VRAM が返ります**。通知領域のアイコンとその右クリックの品書きは**無くなりました**。
  最小化はこれまでどおりタスクバーへ。「サーバ停止」の釦はそのままです。
  ※ 2 個目を起こそうとしたときに 1 つ目の窓が前に出る挙動は、これまでどおりです。
- **ドライバに合わない実行系を選べなくなりました。**前の版は、CUDA 版の初回取得ウィザードが既定で cu130 を
  選んだままで、ドライバが 580 未満の機体でもそのまま取得へ進めてしまい、**取得は終わるのにサーバが起動できない**
  という行き止まりがありました。いまは**ドライバを見て勧める方（580 以上なら cu130・528.33 以上 580 未満なら cu126）を
  最初から選び**、下限に足りない実行系を選んでいる間は「この構成で取得を始める」を**押せなくします**
  （理由を 1 行で出します＝例「このドライバ（537.58）では CUDA 13.0 は動きません。CUDA 12.6 を選んでください。」）。
  **CPU はいつでも選べます**。設定画面から後で替えるときも同じ規則です。ドライバの版が読めなかった機体では、
  その旨を出したうえで選べるままにします。
- **ログが檔に残るようになりました**＝`%LOCALAPPDATA%\irodori-tts-ywk\logs\launcher-<年月日>.log`（1 日 1 檔・UTF-8）。
  画面の記録帯に出る行と、サーバが吐く行と、初回取得の画面に出る行が、そのまま溜まります。うまくいかないときは、この檔を見てください
  （報告にも添えられます）。前の版では `logs\` は空のままでした。
- **状態帯が見つけた GPU が、設定にも残るようになりました。**前の版は、設定画面を 1 度も開かないまま使っていると
  設定の GPU の欄が空のままでした。
- **停めている間に直した話者一覧が、次の起動でそのまま効くようになりました**（起動のたびに話者の台帳を書き出します）。
- （前の版から）**新しい版で増えた同梱の話者が、起動したときに自動で入ります**＝v1.0.2 で入った直しです。
  自分で消した話者は戻りません。

## 落とす物

| 檔 | 何 |
|---|---|
| `irodori-tts-ywk-setup-v1.1.0-cuda.exe` | **CUDA 版**＝「irodori-TTS for 読み分けちゃん（CUDA 版）」（cu130／cu126／CPU を選べる） |
| `irodori-tts-ywk-setup-v1.1.0-radeon.exe` | **ROCm 版**＝「irodori-TTS for 読み分けちゃん（ROCm 版）」（rocm-gfx1151／CPU） |

**どちらを選ぶか**

- **NVIDIA の GPU** → CUDA 版（ドライバが 580 以上なら cu130・580 未満なら cu126 を最初から選びます。cu126 は 537.58 で実測済み）
- **Radeon（gfx1151＝Ryzen AI MAX+ 395／Radeon 8060S）** → ROCm 版
- **GPU が無い／使わない** → どちらでもかまいません（どちらも **CPU 変種**を選べます。ただし遅い＝下の「制約」）

2 本は**同じ機体に同居できます**（導入先は別・取得物の置き場は共有。ただし**走らせられるのは同時に 1 個体だけ**で、
**両方を入れた機体で読み分けちゃん2 が自動で選ぶのは ROCm 版**です＝`docs/install.md` §0）。
※ SmartScreen が出たら「詳細情報」→「実行」（**出るかどうかは未実射**）。

## 必要なもの

- **Windows x64**。
- **per-user 導入**＝導入で管理者権限（UAC）を求めません（インストーラのログに `User privileges: None` と出ます）。
  ※ 初回取得で `vc_redist.x64.exe`（≈24.4 MiB）を通すときだけ **UAC が 1 回**出ます
  （`msvcp140.dll` が在る機体では黙って飛ばします）。※ アンインストールでは UAC が出ることがあります。
- **初回起動でネットから取ります**＝実行系（埋め込み Python ＋ wheel）とモデル。**オフライン導入はありません**。

| 変種 | 落とすバイト | 取得中に要る空き |
|---|---|---|
| cu130（ドライバ 580 以上） | 5.26 GiB | 11.56 GiB |
| cu126（ドライバ 580 未満） | 5.93 GiB | 14.45 GiB |
| rocm-gfx1151（ROCm 版） | 4.79 GiB | 9.55 GiB |
| cpu | 3.62 GiB | 4.53 GiB |

- 所要の条件は「100 Mbps 級で **10 分以内**」（`docs/acceptance.md`）。帯域を絞った実測はまだありません。
- 導入後のディスク＝**合計 約 8.4 GB**（アプリ樹 約 106 MiB 込み・取得キャッシュを除く。
  実測＝cu126 **8.38 GB**／rocm **8.29 GB**・**cu130 は未実測**＝`docs/acceptance.md`）。

## 導入の流れ

1. setup を実行する（中は 3 クリック＝次へ／インストール／完了）。完了頁の「実行する」（既定 ON）がランチャを起こします。
2. 初回取得ウィザードは**押下 5**＝同意チェック → 同意して次へ → 変種を選ぶ → 取得を始める → **発話テストへ**
   （成功した段は自動で次へ進みます）。**変種は、ドライバに合う方が最初から選ばれています。**
3. 「**発話テスト**」のタブで、本文と話者を選んで 1 発鳴らす。
4. 読み分けちゃん2 側は配布版エンジンを有効にするだけです（本体が `/health` で見つけます）。
   ※ **10 番目のエンジン（`irodori-ywk`）に対応した読み分けちゃん2** が要ります。

「サーバ起動」を押すと `127.0.0.1:18088` で待ち受けます。**ポートが先に開き、モデルはその裏で載ります**＝
`/health` 200 まで **10 秒以内**（実測 8.9 s）、合成が撃てる「待機」（`runtime.loaded=true`）まで 120 秒以内。
**窓を閉じるとアプリが終わり、サーバも一緒に止まります**（VRAM もそこで返ります）＝使う間は窓を開けたままにしてください。

## 判っている制約

- **ROCm 版は未保障**です。保証できるのは「**gfx1151（Ryzen AI MAX+ 395／Radeon 8060S）で確認済み**」という
  事実だけで、他の Radeon で動くか・速いかは測っていません（`docs/radeon.md`）。ROCm 版は **bf16 固定**です。
- **合成は 1 プロセス 1 本の直列**（`max_concurrent_synthesis` 既定 1）＝
  配信中に「発話テスト」を撃つと読み上げが待たされます。
- **オフライン導入はありません**。**第三者バイナリ（wheel・exe・dll・モデル）を配布物に 1 つも入れない**
  方針のためです（`decisions.md` 8）。唯一の例外は .NET ランタイム（ランチャ exe に焼き込み）。
- **CPU はとても遅い**（実測 RTF 3.33・40 steps・cpu 変種＝`docs/acceptance.md`）＝配信用途には向きません。
  UI で選べるだけの露出です。
- 出力音声には **SilentCipher の非可聴透かし**が既定で乗ります（切る経路は持ちません）。
- 上流の重みには **Ethical Restrictions**（実在人物の声を明示の同意なく複製しない ほか）が付きます＝`README.md` §4 に原文。
